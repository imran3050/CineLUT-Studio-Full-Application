# 🎬 CineLUT Studio

### Transform cinematic LUTs into Lightroom-ready presets.

CineLUT Studio is a free, modern color-grading utility designed to help photographers and filmmakers convert LUT (Look-Up Table) files into Adobe Lightroom-compatible XMP presets.

With a clean, beginner-friendly interface, CineLUT Studio aims to make cinematic color grading easier, faster, and more accessible.

---

## ✨ Features

- **LUT to XMP Conversion** – Convert supported LUT files into Lightroom-compatible XMP presets.
- **Batch Conversion** – Process multiple LUT files in one workflow.
- **Drag & Drop** – Easily import LUT files.
- **Preset Management** – Organize and export converted presets.
- **Modern Interface** – Clean, intuitive, Google-inspired design.
- **Session Persistence** – Retain application session data.
- **PWA Support** – Installable web application.
- **Free to Use** – No subscription required.

## 🚀 Getting Started

### Requirements

- Node.js (LTS)
- npm
- Windows, macOS, or Linux

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate into the project folder:

   ```bash
   cd CineLUT-Studio-Full-Application
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 📸 Application Preview

CineLUT Studio features a modern dark interface designed around a simple and intuitive color-grading workflow.

## 🎨 Supported Workflow

1. Import your supported LUT files.
2. Select one or multiple LUTs.
3. Convert them into Lightroom-compatible XMP presets.
4. Export your converted presets.
5. Import the XMP presets into Adobe Lightroom.

**Note:** LUT-to-XMP conversion may involve color approximation because Lightroom XMP presets and 3D LUTs use different color-processing systems. Results may vary depending on the LUT.
